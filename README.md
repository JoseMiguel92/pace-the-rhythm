## Descripción

Pace The Rhythm es una web app que convierte tu ritmo de carrera en BPM y te recomienda canciones sincronizadas con tu cadencia, con enlaces directos a Spotify para cada resultado.

## 🔧 Stack técnico

- **Angular 21** — arquitectura 100% standalone y signals (`signal`, `computed`, `input`, `output`, `model`)
- **Smart/dumb components** — separación estricta de responsabilidades
- **RxJS + signals** combinados para gestión reactiva del estado
- **Tailwind CSS v4** — diseño minimalista
- **API Reccobeats** — información de canciones y enlaces directos a Spotify
- **Lazy loading** en todas las rutas
- **Despliegue continuo** en Vercel

## 🤖 IA como herramienta de apoyo

Claude se ha usado como copiloto técnico durante el desarrollo: revisión de patrones Angular y resolución de bugs sutiles en la reactividad de signals. El objetivo: acelerar iteraciones, detectar antipatrones y mantener el listón alto en buenas prácticas.

## 💡 Por qué este proyecto

Banco de pruebas para las últimas capacidades de Angular en producción real: signals, arquitectura zoneless-ready y Tailwind v4 sin fichero de configuración.
